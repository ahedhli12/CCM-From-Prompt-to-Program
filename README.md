# From Prompt to Coding: Coding with AI

A 60-minute CCM workshop for students and faculty with no coding experience.
Facilitator: Professor Amjed Hedhli.

You will run a tiny Python program, create a fictional campus adventure with AI, and test an improvement with a partner.

## Quick start
1. Download this repository with **Code > Download ZIP** and extract it, or clone it if you already use Git.
2. In VS Code, choose **File > Open Folder** and open the extracted project folder.
3. Open `hello.py`. Use the Python extension's **Run Python File in Terminal** command. Select the provided Python interpreter if asked.
4. Enter your answer in the terminal and press Enter. Save changes with Ctrl+S (Cmd+S on Mac), then run again.
5. Open `adventure.py` and try a path. Use `PROMPTS.md` with GitHub Copilot Chat to build your version in `my_project.py`.

You need Python 3, VS Code with the Python extension, and access to an AI assistant. No Python packages are required. Your facilitator will provide session account instructions separately. Never upload passwords or account lists here.

If Copilot access fails, use the same prompts in an available AI assistant and copy only the Python code into your file. If Python is unavailable, pair with someone who has it working. A browser Python runner approved by the facilitator is another option.

Terminal alternative: run `python hello.py` or `python adventure.py` from the project folder. Some systems use `python3` or `py` instead of `python`.

## Session agenda
| Minutes | Activity |
|---|---|
| 0–5 | Audience vote and a live adventure demo |
| 5–10 | Run and change `hello.py` |
| 10–18 | A clear prompt and the basics of Python |
| 18–33 | Build and personalize your adventure |
| 33–45 | Partner test and one improvement |
| 45–55 | Thirty-second project showcases |
| 55–60 | Save your work and choose a next project |

## Partner challenge
One person operates the computer. The other predicts results and tests choices. Swap roles halfway through.
Try library/open, library/leave, cafe/listen and cafe/dance. Try LIBRARY with spaces, a blank nickname and an unexpected location. Explain what happened before asking AI to change it.

## Success checklist
- I ran my program and changed its story.
- I tested two paths and an unexpected answer.
- I can explain one input, one decision and one output.
- I saved a copy of my work outside any temporary training account.

## Files
- `hello.py`: tiny first program
- `adventure.py`: working example and backup
- `my_project.py`: your creation space
- `PROMPTS.md`: prompts for building, improving and debugging
- `FACILITATOR.md`: preparation and delivery notes
- `.github/copilot-instructions.md`: workshop guidance for Copilot

The adventure is fictional and does not describe actual campus services or prizes. Review AI code before running it. Use made-up information for practice.
